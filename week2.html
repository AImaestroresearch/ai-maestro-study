엑셀 대시보드 만들기
— 연구공고봇 수집 데이터 대시보드

부산대학교 연구진흥과 · 2026. 8. 27.

▸ 8/31(월) 부서 스터디 세션 자료: 「엑셀 대시보드, 아주 쉽게」 안내문 보기

한 줄 요약: 부서 연구공고 자동수집봇이 매일 쌓는 공고 데이터(8/3~, 407건)를 Google Sheets 안에서 KPI 4개 + 차트 3개 + 마감임박 목록으로 한눈에 보는 대시보드를 만들었습니다. 전부 수식(QUERY·COUNTIFS·ARRAYFORMULA)이어서 봇이 데이터를 적재하면 사람 손 없이 자동 갱신되고, 봇 코드와 원본 데이터는 한 줄도 건드리지 않았습니다.

1데이터 출처 — 이미 돌고 있는 봇의 로그

연구진흥과에는 매일 오전 10시 정부 R&D 통합포털(IRIS)의 새 공고를 가져와 담당자에게 메일로 알리는 Google Apps Script 봇이 가동 중입니다(1회차 이전 구축, PC를 꺼도 구글 서버에서 실행). 봇은 알림과 함께 공고 1건을 1행으로 시트 「공고로그」에 기록합니다 — 공고ID·발견일시·공고일·전문기관·소관부처·제목·접수시작·접수마감·링크·분야·사업명·첨부공고문·AI요약의 13열.

즉 이번 과제는 "데이터를 새로 만드는" 것이 아니라, 이미 자동으로 쌓이는 운영 데이터를 읽히게 만드는 일이었습니다.

2완성된 대시보드

KPI 4개

누적 · 이번 주 신규 · 접수 중 · 7일 내 마감

실측값 407 / 0 / 17 / 8. "이번 주"는 월요일 기준 자동 계산, "접수 중"은 접수시작≤오늘≤접수마감.

차트 3개

주별 신규 추이 · 소관부처 상위 10 · 전문기관 상위 10

QUERY 집계표를 원본으로 삼아 행이 늘어나면 차트도 따라 늘어납니다. 과기정통부·한국연구재단이 각 1위.

마감임박 목록

오늘~14일 내 마감, D-day 순

D-3 이내는 붉게 강조, 각 행에 IRIS 원문 「열기↗」 링크. 오늘(8/27) 마감 2건이 맨 위에 보입니다.

숨김 데이터 시트

「_대시보드데이터」

공고로그를 ARRAYFORMULA로 날짜형 정규화한 사본. 텍스트/날짜가 섞여 들어와도 계산이 깨지지 않게 하는 완충층입니다.

3어떻게 만들었나 — 설계 원칙 3가지

  • 봇과 원본은 무변경. 대시보드는 별도 시트 2장(표시용 + 숨김 데이터용)으로만 구성. 봇 코드·공고로그·트리거는 그대로.
  • 값이 아니라 수식. 모든 숫자·표·차트가 수식/집계표에 연결되어 있어 "만든 날 이후" 갱신 작업이 없습니다.
  • 재생성 가능. 대시보드 자체를 만드는 Apps Script 함수 1개(buildDashboard)로 작성해 두어, 시트를 지우거나 다른 계정으로 옮겨도 1회 실행으로 동일하게 복원됩니다(구축 절차는 부서 매뉴얼에 수록).
항목구현
날짜 정규화IF(ISNUMBER(x), INT(x), DATEVALUE(SUBSTITUTE(x,"/","-"))) — 날짜형·"2026/08/27"·"2026. 8. 27" 혼재 대응
주 시작(월)발견일 − WEEKDAY(발견일, 3)
집계QUERY(… group by … order by count() desc limit 10) 3종 → 차트 원본
마감임박 목록QUERY({D-day, 마감, 기관, 부처, 제목, URL}, "where Col1 >= 0 and Col1 <= 14 order by Col1") + HYPERLINK
강조조건부서식: D-day ≤ 3 → 붉은 굵은 글씨

4실측 검증

  • KPI "7일 내 마감 8" ↔ 목록의 D-0~D-7 행 수 8 — 일치.
  • KPI "이번 주 신규 0" ↔ 공고로그 원본 확인 결과 마지막 신규 발견일 8/19(408행) — 일치.
  • 차트 주별 추이의 첫 막대(08/03 주 ≈400)는 봇 최초 가동 시 기존 공고를 한 번에 적재한 '씨앗 심기'분 — 정상.

부수 발견: 대시보드를 만들자마자 "8/20 이후 8일간 신규 공고 0건"이라는 사실이 눈에 들어왔습니다. 휴가철 공백일 수도 있지만, 봇 상태 점검을 촉발했다는 점에서 대시보드가 이상 감지 역할을 한 첫 사례입니다. 매일 오는 알림 메일만으로는 보이지 않던 패턴입니다.
