1문제 — 도구가 셋이 되자, "어디에 물어야 하지?"부터 고르게 됐습니다

그동안 규정 Q&A 봇, 연구공고봇, 주간회의 취합봇을 만들고 다듬었습니다(1~3주차 결과물). 도구가 늘어날수록 쓰는 사람은 질문하기 전에 "이건 어느 도구에 물을 일인가"를 먼저 골라야 합니다. 고르는 일이 한 번 더 생기면 도구를 쓰는 이유가 줄어듭니다. 그래서 도구를 하나 더 만드는 대신 입구를 하나로 모았습니다.

또 하나, 회의비 기안 전에는 확인할 것이 많습니다. 1인 한도, 주말·공휴일, 결제 시각, 업종, 참석 명단과 인원, 공문 적요 형식, 증빙 서식. 매번 지침을 다시 펼쳐 보는 대신, 적는 순간 같은 기준으로 한 번 훑어 주는 화면을 입구 안에 넣었습니다.

회의비 서류 — 회의 전과 회의 뒤

  • 회의 전: 제목·내용·일시·장소·참석자·단가를 적으면 사전 체크(지침의 1인 한도, 주말·공휴일, 결제 시각, 주류 업종 단어, 명단 수와 인원 수, 외부인)와 기안 공문 본문, 원인행위 입력표가 나옵니다.
  • 회의 뒤: 영수증 총액·실제 인원·결제 시각을 적으면 사후 체크(총액이 예산 안인지, 결제일이 개최일과 같은지 등)와 회의록·영수증 서식에 옮길 문장이 나옵니다.
  • 결과는 「복사」 버튼으로 가져가서 씁니다. 화면을 닫으면 사라집니다. 판정·승인은 담당자와 결재선의 일입니다.

3구조 — Apps Script 파일 세 개, 규칙은 한 곳에

Code.gs

서버: 화면 내려 주기 + 횟수

  • doGet으로 화면을 내려 줌
  • 익명 사용 횟수만 셈(계획·사후 두 가지)
  • 입력을 받는 길(doPost, 요청 값 읽기)이 없음
index.html

화면: 갈래 나누기 · 서류 · 규칙

  • 갈래 나누기와 모든 계산이 브라우저 안에서
  • 규칙 숫자는 RULES와 공휴일표 한 곳에만
  • PC에서 파일을 더블클릭해도 그대로 동작(시연·백업용)

아직 안 된 것다른 재원(국립대육성사업·산학협력단·교비) 회의비 기준 — 재원마다 지침이 달라 7주차에 예외표로. 규정봇 답을 창구 안에서 바로 보여 주기 — 규정봇은 별도 노트북이라 지금은 주소 안내까지. 영수증 사진 읽기·파일 저장은 일부러 넣지 않았습니다(개인정보가 섞일 수 있어서).
바꾸지 않을 원칙적은 말은 서버로 보내지 않는다. 저장하지 않는다. 규칙 숫자는 지침 원문 그대로 한 곳에만. 판정·승인과 최종 확인은 사람.

다시 한 번 — 화면 순서대로 — 처음이어도 그대로 따라 하면 됩니다

  1. 1. 만들기 → 클로드 앱 [Code] 탭, Environment = Local, Project folder = 바탕화면에 새로 만든 폴더, Permission mode = Manual → 위 상자의 문장을 붙여 넣고 Enter. 테스트가 전부 통과했다고 하면 다음으로.
  2. 2. 새 프로젝트 → 크롬에서 학교 계정으로 script.google.com → 새 프로젝트 → 이름을 알아보기 쉽게 바꿈.
  3. 3. 붙여 넣기 → Code.gs 내용을 폴더의 것으로 전부 바꿈 → 왼쪽 ＋ → HTML, 이름 index → 폴더의 index.html 전체 붙여 넣기 → 각각 Ctrl+S.
  4. 4. 배포 → 오른쪽 위 배포 → 새 배포 → 유형 웹 앱 → 실행 계정 나, 액세스 모든 사용자 → 배포 → 권한 승인(처음 한 번) → 웹 앱 URL 복사.
  5. 5. 세 곳에서 열기 → PC 크롬, 휴대폰, 카톡 대화방에 붙여 넣어 카톡 안에서. 예시 버튼 하나를 눌러 안내가 뜨면 끝.
  6. 6. 고칠 때 → 편집기에서 파일 교체 → Ctrl+S → 배포 → 배포 관리 → 연필 → 새 버전 → 배포. 주소는 그대로입니다. 붙여 넣기 전에 지금 열린 파일 이름을 한 번 확인하세요.
