1문제 — 도구가 셋이 되자, "어디에 물어야 하지?"부터 고르게 됐습니다

그동안 규정 Q&A 봇, 연구공고봇, 주간회의 취합봇을 만들고 다듬었습니다(1~3주차 결과물). 도구가 늘어날수록 쓰는 사람은 질문하기 전에 "이건 어느 도구에 물을 일인가"를 먼저 골라야 합니다. 고르는 일이 한 번 더 생기면 도구를 쓰는 이유가 줄어듭니다. 그래서 도구를 하나 더 만드는 대신 입구를 하나로 모았습니다. 자주 묻는 한도·기준은 입구에서 바로 답하고, 더 깊은 것은 출구로 넘깁니다.

있던 것

도구 세 개

규정봇(노트북), 공고봇(메일·대시보드 시트), 취합봇(웹 화면). 각각은 잘 돌지만 문이 셋.

문 하나 + 출구 셋

공개 페이지에 실리는 판이라 출구에는 공개돼도 안전한 주소만 달았습니다. 규정봇은 초대받은 학교 계정만 열리고, 취합봇은 가명으로 만든 데모로 연결합니다.

3구조 — 원본 하나에서 두 판, 주소는 한 곳에

Code.gs

서버: 화면 내려 주기 + 횟수

  • doGet으로 화면을 내려 줌
  • 익명 사용 횟수만 셈(질문 한 번 = ask, 출구 열기 = exit)
  • 입력을 받는 길(doPost, 요청 값 읽기)·시트·메일 호출이 없음
index.html

화면: 답 · 출구 · 산지니

  • 검색·답 찾기가 모두 브라우저 안에서
  • 공개 지침표·글꼴·산지니 그림까지 파일 하나(약 260KB)
  • 원본 하나에서 시연판(파일 하나, 서버 없이)과 배포판을 따로 빌드
links.json · appsscript.json

출구 주소 · 배포 설정

  • 출구 주소는 links.json 한 곳에만. https 주소만 버튼이 됨
  • 웹 앱 = 배포한 사람 권한으로 실행, 누구나 열 수 있음
  • 시간대 Asia/Seoul

지키기로 한 것을 검사로 묶었습니다 — 배포판 31개 · 시연판 47개, 전부 통과해야 배포

// 화면 코드를 그대로 꺼내 node에서 돌리는 검사(일부)
✓ fetch·XHR·sendBeacon·form action·WebSocket 이 없다 · 브라우저 저장소를 쓰지 않는다
✓ 서버 함수는 recordUse·getStats 둘뿐이고, 보내는 값은 ask·exit 뿐(적은 말은 안 보냄)
✓ 개인정보가 섞인 질문은 세지도 보내지도 않는다
✓ 회의비를 물으면 답이 나오고, 찾지 못하면 담당자로 넘긴다
✓ 주소가 비면 "설정되지 않았습니다"만 보이고 버튼은 없다 · https 주소만 버튼이 된다
✓ 규정봇 버튼 아래엔 파일을 올리지 말라는 주의가 붙는다
✓ 부서용(실명 명단) 취합봇 주소는 들어가지 않고, 취합봇 출구는 가명 데모로 간다
✓ Code.gs는 doGet만 있고 doPost가 없다 · 요청 값·시트·메일·URL 호출을 쓰지 않는다
✓ 특정 AI 제품 이름이 없다 · 휴대폰 화면 대비 · 파일 450KB 미만 · 검색 제외(noindex)

누가 나중에 "편하게" 전송이나 저장을 넣으면 위 검사가 바로 빨간색이 됩니다. 새 기능은 검사를 먼저 쓰고(빨강) 화면을 고쳐(초록) 올립니다. 화면 코드와 검사는 Claude Code가 작성했고, 코드는 직접 쓰지 않았습니다.

구분내용
된 것입구 하나(답 카드 + 출구 셋)를 Apps Script 웹 앱으로 배포. 원본 하나에서 시연판·배포판을 빌드하고 검사 31개·47개 통과. 휴대폰 크기(390px) 화면에서 가로로 넘치지 않음 확인. 적은 말은 화면 밖으로 나가지 않음.
아직 안 된 것회의비 서류 만들기(회의 전 사전 체크·기안 문안, 회의 뒤 사후 체크)는 따로 만들어 두었고 7주차에 이 창구 안으로 합칩니다. 다른 재원(국립대육성사업·산학협력단·교비) 기준도 7주차 예외표로. 규정봇 답을 창구 안에서 바로 보여 주기는 하지 않습니다 — 규정봇은 별도 노트북이라 출구 버튼까지. 파일 올리기·저장은 일부러 넣지 않았습니다(개인정보가 섞일 수 있어서).
바꾸지 않을 원칙적은 말은 서버로 보내지 않는다. 저장하지 않는다. 지침 숫자는 원문 그대로 한 곳에만, 출구 주소도 한 곳에만. 판정·승인과 최종 확인은 사람.

다음 계획: ① 7주차 — 회의비 서류 화면을 이 창구 안으로 합치고, 재원별 예외표(국립대육성·산학협력단·교비) 붙이기 ② 써 본 분 피드백으로 예시 질문·지침표 다듬기 ③ 도구 주소가 바뀌면 links.json 한 줄만 고치기.

다시 한 번 — 화면 순서대로 — 처음이어도 그대로 따라 하면 됩니다

  1. 1. 만들기 → 클로드 앱 [Code] 탭, Environment = Local, Project folder = 바탕화면에 새로 만든 폴더, Permission mode = Manual → 위 상자의 문장을 붙여 넣고 Enter. 검사가 전부 통과했다고 하면 다음으로.
  2. 2. 새 프로젝트 → 크롬에서 학교 계정으로 script.google.com → 새 프로젝트 → 이름을 알아보기 쉽게 바꿈.
  3. 3. 붙여 넣기 → Code.gs 내용을 폴더의 것으로 전부 바꿈 → 왼쪽 ＋ → HTML, 이름 index → 폴더의 index.html 전체 붙여 넣기(파일이 커서 몇 초 걸림) → 각각 Ctrl+S.
  4. 4. 배포 → 오른쪽 위 배포 → 새 배포 → 유형 웹 앱 → 실행 계정 나, 액세스 모든 사용자 → 배포 → (권한 확인 창이 뜨면 허용) → 웹 앱 URL 복사.
  5. 5. 세 곳에서 열기 → PC 크롬, 휴대폰, 카톡 대화방에 붙여 넣어 카톡 안에서. 예시 버튼 하나를 눌러 답이 뜨면 끝.
  6. 6. 고칠 때 → 편집기에서 파일 교체 → Ctrl+S → 배포 → 배포 관리 → 연필 → 새 버전 → 배포. 주소는 그대로입니다. 붙여 넣기 전에 지금 열린 파일 이름을 한 번 확인하세요.
